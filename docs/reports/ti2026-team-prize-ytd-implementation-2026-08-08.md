# TI 2026 战队年度已获奖金：实施与验收记录

状态：**实现完成；玩家报告可发布；原始网页快照仍有可复现性限制**

统计截止：`2026-08-08T14:37:14Z`

## 阶段目标、最小范围与验收标准

本阶段只回答一个问题：当前 TI 2026 的 16 支战队，在 2026 年已经结束的赛事中分别公开获得了
多少奖金。它不修改实力模型、胜负概率、Fantasy 推荐或既有赛果。

最小修改包括一份受校验的逐笔账本、一份玩家版累计报告、发布包同步，以及把旧文档中的“赛事
总奖池”与“战队年度已获奖金”明确拆开。验收要求是：

- 16 支队伍必须与 `config/ti2026.yaml` 的稳定 ID 集合完全一致；
- 每笔记录必须有赛事、完赛日、名次、正数金额和至少一个证据来源；
- 完赛日和证据观察时间不得晚于 `as_of`；
- 同一队伍同一赛事不得重复，个人奖和未确认金额不得进入合计；
- 逐笔金额、逐队声明小计和总计必须完全相等；
- 玩家版不显示队伍 ID 和来源链接，仓库研究 memo 保留完整证据链；
- 仓库报告与发布包副本必须由同一账本生成并逐字一致。

## 计算口径

对每支队伍，年度累计就是该队所有合格赛事奖金的直接求和：

`年度已获奖金 = Σ 每项已完赛赛事公开分配给该队的名义奖金`

赛事若把金额拆成 `Player Prize Money` 和 `Club/Team Reward`，本账本先把两项相加，再计入
该队。个人 MVP 不计；只有晋级名额的资格赛不计；有独立现金奖励的资格赛可以计入。唯一非美元
记录沿用赛事明细页在完赛日列出的美元折算。

统计主体是当前组织身份。同一组织的正式改名连续累计，但选手或整套阵容转会前在其他俱乐部
获得的奖金不会转给新俱乐部。

- 21 项赛事、122 条战队获奖记录、16 支队伍；合计 **US$8,204,268.51**。
- 25 条记录为官方奖金规则加社区名次映射，金额 US$2,795,000；可信度标为高。
- 7 条 BLAST SLAM VI 记录有官方赛果与社区历史分配，金额 US$696,250；标为中高。
- 89 条记录来自明确列出队伍、名次和金额的社区赛事明细，金额 US$4,710,000；标为中。
- 1 条为 250,000 RUB 的公开原币奖金及页面汇率折算，金额 US$3,018.51；标为中低。

因此，报告可以可靠表达“截至该时点公开资料能逐项确认的名义获奖额”，但不能声称所有数字都由
主办方付款凭证独立审计，也不能声称奖金已经到账。完整来源、逐笔依据和 unknown/excluded 项见
`docs/research/ti2026-team-prize-ytd-primary-sources-2026-08-08.md`。

## 自动验收与项目影响

`src/ti_predictor/prize_reporting.py` 会校验时间边界、稳定 ID、重复记录、金额组成、来源引用和三层
合计，并从账本生成玩家版 Markdown。专项测试同时锁定 16 队精确名次、金额和三项关键纠错。

这是一条独立的发布报告路径，没有改变训练数据、特征、模型配置或预测结果。赛事奖金仍只作为
玩家理解当年成绩与赛事规模的背景，不参与现有实力模型加权。

当前剩余限制是：研究 memo 保存了 URL、查询时点和逐项证据，但多数社区页面的原始响应没有全部
落盘并记录内容 SHA-256。可机读账本记录了本轮研究 JSON 的 SHA-256；如果以后要做到离线重放式
审计，还需要增加合规的网页/PDF 不可变抓取层。这个限制不影响本轮算术验收，但降低了未来网页
发生改版后完全复现原页面的能力。
