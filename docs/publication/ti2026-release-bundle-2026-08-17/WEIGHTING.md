# TI 2026 Main Event 加权方式

Main 的 Team-strength 与 Fantasy 对同一局比赛使用同一组基础证据轴，并对本届 TI 已结束的
小组赛与突围赛使用相同的 `1.50` 阶段系数。两个通道保持独立配置、独立审计和独立语义哈希；
“同等加权”不表示两种模型会产生相同数值变化。

## 当前公式

```text
单局基础权重 = 大版本权重
             × 当前精确版本倍率
             × OpenDota 赛事目录等级
             × 2^(-距 as_of 天数 / 60)

Main Team-strength 权重 = 单局基础权重 × 当前赛事阶段倍率
Main Fantasy 权重       = 单局基础权重 × 当前赛事阶段倍率
```

| 因子 | 当前值 |
| --- | ---: |
| 目标大版本 7.41 | 1.00 |
| 相邻大版本 7.40 | 0.15 |
| 更早大版本 | 0.00 |
| 当前精确版本 7.41e | 在 7.41 基础上再乘 1.50 |
| OpenDota `premium` | 1.00 |
| OpenDota `professional` | 0.75 |
| 其他或未知赛事目录等级 | 0.00 |
| 时间衰减 | 每 60 天减半 |
| TI 2026 已结束小组赛与突围赛 | 再乘 1.50 |

因此，一场刚结束、属于 `premium`、版本为 7.41e 且位于冻结 TI 阶段集合内的比赛，典型权重
约为 `1.00 × 1.50 × 1.00 × 1.00 × 1.50 = 2.25`。两个 `1.50` 分别表达“当前精确版本”
和“当前赛事表现”，不是同一轴重复计算。

## 阶段范围怎样锁定

阶段乘数不按队名、日期猜测，也不对整个 League 无条件放大。正式配置只接受冻结的
`match_id` 集合：

- League：TI 2026，`league_id=19719`
- 范围：Main 开始前已完成的小组赛与突围赛
- 冻结 Game：`109 / 109`
- 缺失或 League 冲突：`0`
- match ID 集合 SHA-256：
  `3bfecfc99e0ce51e7ce621093e8d3748b1b412c4207e2c92d5e5f0f169277fc4`
- 数据与模型 `as_of`：`2026-08-16T15:31:30Z`

任何晚于 `as_of` 的 Main 赛果都不能进入这次运行。以后刷新必须产生新的数据快照、policy
identity 和运行身份，不能覆盖本版本。

## Team-strength 怎样响应

Elo/Glicko 按时间顺序读取加权比赛。阶段倍率会改变每次更新的步幅和 Glicko 不确定性，因此
不会给八支队机械地加同一个分数。

| 队伍 | 1.0× 综合强度 | 1.5× 综合强度 | 变化 |
| --- | ---: | ---: | ---: |
| TEAM VISION | 1820.58 | **1853.28** | +32.70 |
| Team Liquid | 1745.28 | **1772.56** | +27.29 |
| Nigma Galaxy | 1693.68 | **1735.60** | +41.92 |
| Iron Wing | 1702.12 | **1719.54** | +17.42 |
| Team Falcons | 1685.58 | **1688.60** | +3.02 |
| Team Spirit | 1673.83 | **1685.48** | +11.65 |
| Team Yandex | 1674.18 | **1673.14** | -1.04 |
| BoomBoys | 1664.37 | **1669.62** | +5.25 |

例如 Nigma–Falcons 的当前首轮节点概率由 1.0× 时的 `51.17%` 变为 1.5× 时的 `56.68%`；
Liquid–Yandex 由 `60.01%` 变为 `63.83%`。这是阶段证据改变相对强度后的结果。

Team-strength 证据范围是当前政策下的正权重连通网络，而不是把 2026 年全部职业比赛详情都
强行下载和入模。本次最终入模 `4,069` 场，有效权重 `948.099939`；其中冻结 TI 阶段有效权重
为 `239.546948`。

## Fantasy 怎样响应

Fantasy 使用目标选手的全局正权重历史，而不是 Team-strength 的队伍连通网络。相同 TI
Game 仍使用同一个 `1.50` 证据判断，但应用方式不同：

1. 每局先计算完整单局权重。
2. 选手统计估计读取该权重；缺失值继续保持 `null`。
3. 完整 BO2/BO3 Series 的重采样权重取 Series 内各局权重的平均值，再在候选池内归一化。
4. 不把原始击杀、GPM、插眼等观测数值乘 1.5，也不在 Game、Series 和最终得分三个层级重复乘。

当前 Fantasy 证据包含 `4,555` 场正权重 Game、`3,636` 场合格 BO2/BO3 Game 和 `1,481`
个结构完整 Series。实际 Main 八队的 Core / Mid / Support 池都是 `8 / 8`。

## 不进入权重的内容

- 社区主观 Tier、赛事总奖池、年度奖金、名次和博彩盘口不进入历史证据权重。
- 队名相似不构成身份桥；评级只按稳定 ID 和带生效区间的身份规则连接。
- 未知版本、未知或未批准赛事目录等级、缺失结果的比赛保持排除，不补猜权重。
- 本次阶段 `1.50` 是在赛果产生前冻结的研究决策，不根据当前推荐看起来是否顺眼事后调整。
