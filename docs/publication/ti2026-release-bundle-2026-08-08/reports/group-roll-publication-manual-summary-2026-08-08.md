# Group 40 Roll 玩家手册：易懂总结

## 去哪里看

直接打开 [Group 40 Roll 玩家手册](../playbooks/group-roll/group-roll-publication-manual-v2.md)。

它不是把原来的两本草案硬说成“可靠”，而是把已经确认的机制、查表结论、较强规则、条件规则和
失败规则分开写。阅读顺序就是确定度从高到低：S → A → B → C → D。

## Roll 到底怎样运作

你有核心位、中单、辅助位三面战旗，每面三格，共 40 次 Roll。屏幕上的三个选项是三面战旗共享
的，但执行一个选项时只会改变你选中的那一面。

每次要么使用一个选项，要么刷新三个选项。两种操作都消耗 1 次 Roll，之后三个选项都会一起
换新。属性重随只改被点名的 Stat、品质或 Trait，可能抽回原值；刷新不改战旗，但也不是免费的。

最后三格必须由同一支队伍兑现，所以不能把三个 Stat 各自的队伍第一名直接拼在一起。

## 当前最值得先看的四条规则

这四条在三种出现率模型下都显示有用，是手册里的 B 级：

1. 看见“随机一格品质 +1”，优先给还没有全 T5 的战旗；
2. 中单蓝色是瞭望台、假眼或诡计之雾时，优先接受只修这一格的 Stat 选项；
3. 剩余 10 次或更少，只做“最差可能结果也不比现在低”的动作；
4. 前中期遇到稳定的绿色“可以改善”Stat，只在选项精确影响这一格时考虑。

它们是当前最强的单规则证据，但四条拼在一起还没有被证明是完整 40 步最优策略。

## 其次才看的条件规则

如果没有命中上面四条，而且你能计算完整战旗的平均分，可以再看 C 级：稳定绿色差 Stat、单格
或两格 Stat、整色品质、前期低品质二升一降。共同条件都是：重新做同队匹配后，完整战旗的平均
改善必须大于 0。

“平均改善为正”不是说这一次一定涨分。它只是说把各种可能结果按当前模型平均后更好；没有计算
工具或无法判断时就不要凭感觉使用。

## 当前不要机械执行的做法

- 不要因为 T1/T2 的单格平均值偏低，就见到品质重随必点；
- 不要为了只差一个 Trait 就默认追套装，也不要广泛重随 Trait；
- 不要把末期的“所有结果不降”扩大到前中期；
- 不要认为把最低改善门槛提高到 2% 或 5% 就一定更稳；
- 不要整本照抄 Primary 或 Rate 候选，它们都仍是草案。

## 实际使用顺序

1. 先核对三面战旗、三个共享选项和剩余次数；
2. 用 Stat Top 3 表、Quality 表和 Trait 配方判断当前状态；
3. 严格检查是否命中 B 级规则；
4. 能算完整战旗平均收益时，再检查 C 级；
5. D 级不作为默认操作；
6. 没有明确命中就刷新，操作后根据真实新结果从头判断。
