# 当前屏幕 Roll 顾问 v2 实装计划

## 目标

把现有实验页改成可实际使用的“实时重随顾问”：玩家手工录入当前三面战旗、当前三个 Roll 选项和剩余次数，系统只回答此刻应把哪个选项用于哪面战旗，或建议刷新。玩家在游戏内操作后，直接把页面输入改成新的实际画面并重新计算。

页面同时根据当前战旗对应的 Core、Mid、Support 队伍组合，自动给出 Title 的 Prefix 与 Suffix 推荐。

## 明确不做

- 不生成、猜测或代替玩家录入下一轮 Roll 选项。
- 不控制 Dota 客户端，不自动点击或填写。
- 不宣称找到 40 次 Roll 的全局最优路线。
- 不把当前仍未完整验证的 Title 条件加入 Roll 分值；Title 作为独立的纸面期望估算展示。
- 不支持 Main 阶段五格战旗。

## 最小修改范围

1. 新增 v2 配置，冻结当前 `as_of`、P3 数据/场景、Title 证据、随机种子、风险参数和本地边界。
2. 新增当前屏幕分析模块，直接重建当前 P3 算术上下文，不依赖旧 P4/P5/P6 或旧手册结论。
3. 为自动队伍组合及用户指定队伍组合计算每个合法单步动作。
4. 将当前 Title 证据按三个位置的当前预计贡献加权，分别排名 Prefix 和可推荐 Suffix。
5. 重写现有 Streamlit 页面为下拉式表单和清晰的主建议；保留旧 v1 代码与历史证据，不作为 v2 运行依赖。
6. 补充单元、集成、页面烟雾、性能与项目级回归测试。

## 推荐语义

- **可以选择**：默认模型下平均收益和低迷情景收益均高于当前战旗，并且多个出率模型给出同一首选。
- **有条件选择**：默认模型平均收益为正，但低迷情景或模型之间有分歧；页面必须显示风险。
- **建议刷新**：当前三个选项没有达到上述接受条件。这里仅表示“拒绝这三个选项”，不估计刷新后未知选项的价值。
- 所有收益均相对“不改变当前战旗”的基线；一次应用只比较当前操作的直接结果。

## Title 语义

- 自动模式使用当前战旗下按风险规则匹配出的 Core、Mid、Support 队伍。
- 手动模式使用玩家为三个位置指定的队伍。
- 每个位置的历史 Title 触发率来自该位置对应的稳定选手 ID 池。
- 三个位置按当前战旗的预计基础贡献加权后，分别计算 Prefix 和 Suffix 的纸面平均加成。
- 有客户端冲突或观测不可用的 Suffix 永不进入推荐候选。
- 结果是阵容适配估算，不是包含赛事赛程、选人顺序和全周期优化的精确答案。

## 验收标准

1. 页面能用下拉菜单完整录入九格战旗和三个互不重复的 Roll 选项。
2. 相同证据、配置、种子与输入产生相同 JSON 结果。
3. 输出唯一主建议、建议等级、平均变化、CVaR10 变化、无关出率区间和模型分歧。
4. 支持自动队伍组合与手动指定三个位置队伍；手动组合必须原样进入评分。
5. Title 至少展示前三 Prefix、前三可推荐 Suffix、触发率、纸面平均加成和选择依据。
6. 刷新不会被赋予虚构的未来选项收益，且页面明确提示玩家更新实际画面后重算。
7. 当前 P3、Title 或规则身份漂移时拒绝发布相关结果。
8. Group 页面本地运行无异常；Main 明确拒绝；既有测试和项目级检查通过。
9. 冷启动和单次计算达到配置中的性能门槛。

## 阶段

1. 当前证据上下文与身份门禁。
2. 单步动作与队伍组合分析。
3. Title 阵容适配排名。
4. 下拉式 UI/UX。
5. 测试、性能、工程审查和旧入口收口。
6. 总结报告、提交并推送 `main`。
