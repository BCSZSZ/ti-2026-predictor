# Group Roll 实时顾问 v2：易懂总结

## 现在能做什么

打开本地网页的 `Group Roll 实时顾问`，用下拉菜单录入：

- 核心位、中单、辅助位共九格战旗；
- 游戏当前显示的三个 Roll 选项；
- 剩余 Roll 次数；
- 让系统自动选三个位置的队伍，或自己指定队伍组合。

点击计算后，页面会明确回答：把哪个选项用在哪一面战旗，还是刷新当前三个选项。页面同时显示推荐的可信程度、平均分变化、低迷情景变化、最差与最好合法结果，以及其他当前可执行动作的顺序。

在游戏里完成操作后，不需要让程序生成下一轮。只要把页面改成实际出现的新战旗、新三个选项和剩余次数，再计算一次即可。

## 建议怎样判定

- **可以选择**：平均表现和最差 10% 情景都改善，所有合法结果不低于当前战旗，而且三种出率假设给出同一个首选。
- **有条件选择**：平均表现改善，但低迷情景、最差合法结果或出率假设存在风险。页面会把具体风险直接列出。
- **建议刷新**：当前三个选项没有可接受的直接改善。刷新只表示拒绝这一屏，不代表程序知道下一屏会出现什么。

这是“一步建议”，不是对剩余 40 次 Roll 的全局路线承诺。它不虚构未知的下一轮选项价值。

## Title 怎样自动计算

系统先确定当前核心位、中单和辅助位分别使用哪支队伍。每个位置只使用该队对应位置的稳定选手 ID 历史池，不会把全队五人混在一起。

然后按三面当前战旗各自的预计基础贡献加权，分别计算：

- Prefix 的前三名；
- 排除客户端冲突或无法可靠观测条件后的 Suffix 前三名；
- 当前推荐的 Prefix + Suffix 组合。

页面显示触发率和纸面平均加成。由于现有证据没有 Prefix 与 Suffix 在同一局同时触发的完整联合分布，组合加成只作两项纸面均值的简单相加，不能当作最终结算保证。Title 目前独立展示，没有偷偷加入 Roll 动作分值。

## 数据与版本

- 数据截止：`2026-08-08T13:12:00Z`。
- 当前精确版本 7.41e 使用 1.5 倍权重；其他既有版本、赛事级别和时间权重保持冻结政策。
- 核心 P3 证据：`94c3313c62f8…`。
- Title 证据：`d9a57ea0d57c…`。
- 页面启动时会重新构造数据快照、完整系列赛池和场景，并核对冻结身份；身份漂移时拒绝给出结果。

## 实际验收结果

- 真实数据冷启动：17.8 秒，门槛 30 秒。
- 第一次一步分析：0.59 秒，门槛 10 秒。
- 相同上下文缓存重算：0.05 秒，门槛 1 秒。
- 同输入重复计算：完整结果和分析指纹完全一致。
- 自动队伍模式：通过。
- 手动三位置队伍模式：指定 ID 被原样保留并进入评分。
- Streamlit 默认输入、三个独立选项下拉框、手动队伍下拉框、推荐与 Title 渲染：通过。
- 浏览器视觉验收：通过；Title 前三已改为无需横向滚动的卡片式排列。
- 全项目：Ruff 通过；Pytest `174 passed, 1 skipped`。

测试中出现一个既有 NumPy 时间单位弃用警告，不影响本次结果，也不是本次改动产生的功能回归。

## 旧代码怎样处理

旧 v1 页面入口已经被替换，当前页面不读取旧 P4/P5/P6 或草案手册。旧会话、旧 P5/P6 诊断和 `group-advisor-evidence` 命令仍是可复现的历史证据与兼容工具，因此没有删除；它们不再参与当前页面运行。

## 使用边界

- 只支持 Group 三格战旗；Main 五格仍拒绝执行。
- 不控制 Dota，不自动填写，不保存 Steam 凭据。
- 不生成下一轮 Roll，不声称全局最优。
- 当前 Title 是阵容适配估算，不是完整赛期联合优化。
